## Closures in my code
Я применил замыкания (closures) в двух функциях: `memoize` и `counter`. Замыкание — это способность функции запоминать лексическое окружение, в котором она была создана, даже после того, как внешняя функция завершила работу. В функции `counter` переменная `count` скрыта от прямого доступа извне, но возвращаемые методы `inc`, `dec` и `value` навсегда сохраняют к ней доступ. Это позволяет создать надежное приватное состояние для каждого нового счетчика. Аналогично, в функции `memoize` замыкание используется для сохранения объекта `cache` (Map). Возвращаемая функция имеет постоянный доступ к этому кэшу между разными вызовами, что позволяет мгновенно возвращать уже вычисленные результаты.
